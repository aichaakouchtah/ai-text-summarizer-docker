║                    FLUX DE DONNÉES DÉTAILLÉ                              ║
╚══════════════════════════════════════════════════════════════════════════╝

1. DÉMARRAGE DU BACKEND
   ────────────────────
   Backend démarre
   │
   ├─> Charge Flask (serveur web)
   │
   └─> Charge BART (modèle IA) ⏱️ 30s-2min
       │
       ├─> Télécharge le modèle (1.6 Go) si première fois
       │
       └─> Charge en mémoire RAM (~2-4 Go)
           │
           └─> Prêt à résumer !


2. REQUÊTE DE RÉSUMÉ
   ──────────────────
   Frontend → Backend : POST /summarize
   │
   ├─> Backend reçoit : {"text": "...", "max_length": 150}
   │
   ├─> Validation : texte ≥ 30 mots ?
   │   ├─> NON → Erreur 400
   │   └─> OUI → Continue
   │
   ├─> Appel BART : summarizer(text, max_length, min_length)
   │   │
   │   ├─> BART lit le texte (tokenisation)
   │   │
   │   ├─> BART analyse (compréhension du sens)
   │   │
   │   ├─> BART identifie les idées principales
   │   │
   │   └─> BART génère le résumé ⏱️ 2-10 secondes
   │
   └─> Backend → Frontend : {"summary": "...", "original_length": 250}


3. AFFICHAGE
   ─────────
   Frontend reçoit la réponse
   │
   └─> Affiche :
       ├─> Statistiques (longueur, compression)
       └─> Résumé généré


╔══════════════════════════════════════════════════════════════════════════╗
║                    ANALOGIE SIMPLE                                       ║
╚══════════════════════════════════════════════════════════════════════════╝

Imaginez un RESTAURANT :

┌─────────────────────────────────────────────────────────────────────────┐
│  CLIENT (Frontend)          SERVEUR (Backend)        CUISINE (BART)      │
│                                                                           │
│  "Je veux un résumé"   ──►  Prend la commande   ──►  Prépare le résumé  │
│                                                                           │
│  Reçoit le résumé      ◄──  Apporte le plat      ◄──  Résumé prêt       │
└─────────────────────────────────────────────────────────────────────────┘

• Le CLIENT = Frontend (vous, l'utilisateur)
• Le SERVEUR = Flask (prend les commandes, sert les résultats)
• La CUISINE = BART (fait le vrai travail de résumé)

BART est comme un chef qui a étudié des millions de textes et leurs résumés,
et qui sait maintenant comment résumer n'importe quel texte automatiquement !
